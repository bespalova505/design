# Найденные проблемы исходника

Оригиналы в `archive/raw/` и извлеченные примеры сохранены с ошибками. Исправления применены только в `portable/`. Наблюдения: публичная версия на 25.09.2026.

| Проблема | Доказательство | Последствие | Действие |
| --- | --- | --- | --- |
| Portrait query без единицы | `extracted/inline/global-02.css`: `(max-width: 478)` | Ненулевая длина без единицы не активирует переключение | В portable принято `479px` согласно остальным границам шаблона |
| Цикл H6 на tablet | CSS: `--heading--md--h6: var(--heading--h6)`; inline на tablet делает обратную ссылку | Размер через этот токен становится недействительным | `--heading--md--h6: 1.25rem` |
| Потенциальный цикл H6 на portrait | `--heading--xs--h6: var(--heading--h6)` и обратная ссылка | Проявится после исправления media query | `--heading--xs--h6: var(--heading--sm--h6)` |
| Некорректные правила hide | `global-01.css`: повтор `@media` после запятых, пропущенные `{` | Часть правил отбрасывается; CSSOM показывает `not all` | Эти правила не включены в portable |
| Radio является checkbox | `extracted/components/form.original.html`: `id="Radio 1" type="checkbox"` | Нет поведения радиогруппы | В portable настоящие radio с общим name |
| Кнопки обходят семантический слой | `.button` напрямую использует `--swatch--dark-1` | Изменение семантического цвета не обязательно меняет кнопку | Отдельные семантические токены кнопки в portable |
| Историческая инструкция | Designer Guide: Client-First еще не поддерживает variables | Устаревший факт в базе | Ссылка на официальный раздел Variables |
| Недоступный placeholder | HTTP 403 для `placeholder.60f9b1840c.svg` в manifest | Часть демонстрационных иконок отсутствует | URL и ошибка сохранены; полнота не завышается |

В CSS также встречаются комментарии `//`, не являющиеся стандартным синтаксисом CSS. Этот участок не включен в независимую основу.

## Проверка

`verify_archive.py` сравнивает SHA-256 исходных HTTP-тел с manifest, проверяет локальные пути и зависимости токенов в типичных ширинах экрана. Для оригинала отдельно фиксируется цикл H6 на tablet. Для исправленной основы циклов и отсутствующих токенов быть не должно.

Оригинал просмотрен в браузере. Desktop-скриншот не является проверкой мобильного вида. Полный визуальный QA будущего клиентского сайта остается задачей конкретного проекта.
