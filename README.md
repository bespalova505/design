# Design reference: Variable Design System

Исследование и локальная копия [Variable Design System](https://variable-design-system.webflow.io/) Caleb Raney. Дата сбора: 25 сентября 2026. Это база знаний и материал для адаптации; исходные правила не объявлены стандартом всех проектов агентства.

**Полезно для системности дизайна и верстки:** токены, адаптивные отступы, типографика, именование и повторяемые элементы. Визуальную концепцию проекта нужно разрабатывать отдельно. [Полный разбор](docs/01-analysis.md).

| Объект | Результат |

| Скачанные статические ресурсы | 48 из 49 запрошенных URL |

**Граница полноты:** это архив опубликованного сайта, а не исходный проект редактора Webflow. Неизвестные неопубликованные страницы и внутренняя модель компонентов не извлекались. Один стандартный placeholder SVG вернул HTTP 403; запись сохранена в [manifest](data/archive-manifest.json). Внешние статьи, Loom-видео и их плееры оставлены ссылками. Отправка форм и серверные функции не перенесены. Это не полностью автономная копия всех внешних сервисов.

## Структура

| Путь | Назначение |
| --- | --- |
| `archive/raw/` | Исходные HTTP-тела HTML, CSS, JS, изображений и шрифтов без правок |
| `archive/site/` | Копия для просмотра с локальными ссылками на скачанные ресурсы |
| `data/` | URL, статусы, SHA-256, страницы, токены, классы и варианты кнопок |
| `extracted/` | CSS-вставки и примеры компонентов из оригинала |
| `portable/` | Исправленные токены и небольшой пример на обычных HTML/CSS |
| `docs/` | Анализ, карта, ограничения и инструкция использования |
| `evidence/` | Скриншот и результаты проверки |
| `scripts/` | Воспроизводимые сбор, извлечение, каталог и проверка |

## Обновить и проверить

Скриптам нужен Python 3.10+ и `lxml` (см. requirements.txt).

```bash
python3 scripts/archive_site.py
python3 scripts/extract_reference.py
python3 scripts/build_catalog.py
python3 scripts/verify_archive.py
```

Повторная выгрузка обновляет состояние публичного сайта. Отчет анализа составлен вручную: после обновления проверить выводы и счетчики, а перед коммитом просмотреть diff.
